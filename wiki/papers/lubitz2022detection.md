# 以穿戴裝置偵測心房顫動：Fitbit 心臟研究（Lubitz et al., 2022）

**APA 7：** Lubitz, S. A., Faranesh, A. Z., Selvaggi, C., Atlas, S. J., McManus, D. D., Singer, D. E., Pagoto, S., McConnell, M. V., Pantelopoulos, A., & Foulkes, A. S. (2022). Detection of atrial fibrillation in a large population using wearable devices: The Fitbit Heart Study. *Circulation, 146*, 1415–1424. https://doi.org/10.1161/CIRCULATIONAHA.122.060291

> 在本知識庫的定位：**核心文獻**。用途：了解疾病與技術、找出預測特徵與預測目標。
> 強調：研究設計（可模仿）、時間序列資料怎麼標記結果；另補充「**自己跑模型需要的技術**」。

## 一句話摘要
Fitbit 手錶以 [[photoplethysmography|PPG]] 量脈搏，演算法在靜止時偵測到持續 ≥30 分鐘的不規則心律就發通知；在同步配戴心電圖貼片期間，通知的 PPV 達 98.2%（p.1415）。

## ⭐ 疾病與技術
- **疾病**：[[atrial-fibrillation|心房顫動 (AF)]]，會增加中風、心衰竭風險；常無症狀或陣發性，不易被發現（p.1415–1416）。
- **資料**：美國 455,699 位 Fitbit 使用者（中位年齡 47 歲、女性 71%、白人 73%），2020/5/6–10/1 遠距入組（p.1415）。
- **技術**：[[wearable-devices|穿戴裝置]]的光學 PPG 感測器 + 加速度計；演算法在中央伺服器執行（手錶同步後分析）（p.1416）。

## ⭐ 預測特徵與預測目標
- **輸入（特徵）**：靜止期間（由加速度計判斷）的 PPG 脈搏資料，整理成 5 分鐘的脈搏間隔序列（tachogram）（p.1416）。
  - ⚠️ 演算法如何判定每段「不規則」，原文未公開（只說由 Fitbit 開發，研究開始前已固定）（p.1417）。
- **偵測結果**：連續 11 段 tachogram 都不規則（≥30 分鐘）→ 不規則心律偵測（IHRD），發通知（p.1416–1417）。
- **參考標準（真實答案）**：一週單導程心電圖貼片；心房顫動持續 ≥30 秒才算；由心臟科醫師判讀（p.1417）。
- **主要結果指標**：第一次 IHRD（在貼片配戴期間）的 PPV（p.1417）。

## ⭐ 研究設計（可模仿）
1. **事先註冊、事先固定演算法**：NCT04380415；演算法在研究開始前固定，中途不修改（p.1415, p.1417）。
2. **單組遠距臨床試驗**：透過 App、Email、社群招募；線上知情同意；IRB 審查（p.1416）。
3. **確認流程**：IHRD 通知 → 遠距看診（確認資格、病史）→ 郵寄一週心電圖貼片 → 第二次遠距看診說明結果（p.1417）。
4. **同步比對**：用貼片期間「同一時間」的心電圖判讀手錶的 IHRD，避免時間錯開（p.1417）。
5. **事先計算樣本數**：目標 155 位「貼片期間有 IHRD」者，80% 檢定力、單尾 α = 2.5%，檢驗 PPV >70%（預期 80%）（p.1417）。
6. **分層報告**：性別、年齡（<65、≥65）、[[cha2ds2-vasc|CHA₂DS₂-VASc]] 中風風險分數（p.1417）。
7. **信賴區間**：Clopper-Pearson 精確區間（p.1418）。
8. **追蹤調查**：通知後 90 天問卷、研究結束問卷（新診斷、用藥、處置）（p.1417, p.1421）。

## ⭐ 時間序列與結果標記
詳見 [[sliding-window]]。
```
PPG（靜止時）：|--5分--|
                   |--5分--|            每 2.5 分鐘取一段（重疊 50%）
                       |--5分--| ...
判定：           不規則 × 連續 11 段（≥30 分鐘）→ IHRD = 1
```
| 項目 | 做法 | 頁碼 |
|---|---|---|
| 分析單位 | 5 分鐘 tachogram（重疊 50%）；彙總到「人」 | p.1416–1417 |
| 陽性規則 | 連續 11 段都不規則 → IHRD | p.1416 |
| 只用靜止時段 | 加速度計判斷，減少動作雜訊造成的偽陽性 | p.1416 |
| 風險期 | 從手錶資料開始（最早入組前 30 天）到第一次 IHRD 或監測結束（2020/10/26） | p.1417 |
| 累積發生率 | 90 天 IHRD 累積發生率 0.94%（至少戴 1 小時者） | p.1419 |
| 參考標準配對 | 只看貼片期間的 IHRD；每段對應心電圖前後各加 1 分鐘緩衝 | p.1417 |
| 貼片時限 | 通知後 45 天內開始配戴；至少 1 小時可讀心電圖與同步 PPG | p.1417 |
| AF 定義 | 心電圖上持續 ≥30 秒 | p.1417 |

- 回溯 vs. 前瞻資料：51.2% 的 IHRD 來自入組前 30 天的回溯資料；兩者累積發生率相近（p.1419）。
- ⚠️ 推論：「連續 N 段才算陽性」是用**提高特異度、犧牲敏感度**的方式降低假警報；和 [[time-series-outcome-labeling]]（Kausch 的「未來 3 天內」）不同，這裡是「同時發生」的偵測，不是「提前預測」。

## ⭐ 如果要自己跑模型，需要什麼技術
詳見 [[ppg-af-modeling-pipeline]]。以下除標註頁碼者外，皆為 ⚠️ 推論（一般做法，原文未公開演算法細節）。

| 步驟 | 要做什麼 | 常用技術／工具 |
|---|---|---|
| 1. 取得資料 | PPG 波形 + 同步心電圖標註 + 加速度計 | 本研究資料**不公開**（p.1416, p.1418）；需另找公開資料集或自行收案（例如 PhysioNet 上的波形資料庫，需查證是否含 PPG 與 AF 標註） |
| 2. 訊號前處理 | 濾波去雜訊、偵測每一下脈搏峰值、算出脈搏間隔 | 帶通濾波、峰值偵測；Python：SciPy、NeuroKit2、HeartPy |
| 3. 去除動作干擾 | 只保留靜止時段 | 加速度計門檻（本研究做法，p.1416） |
| 4. 切視窗 | 5 分鐘、重疊 50% | pandas 滑動視窗（本研究參數，p.1416） |
| 5. 特徵工程 | 每段算心律不規則程度 | 心率變異度指標（RMSSD、pNN50、SDNN）、熵（樣本熵、Shannon 熵）、Poincaré 圖指標 |
| 6. 建模（每段分類） | 判斷每段是否不規則 | 傳統：邏輯斯迴歸、隨機森林、XGBoost；深度學習：1D CNN、LSTM 直接讀波形（PyTorch／TensorFlow） |
| 7. 彙總規則 | 連續 N 段陽性才發通知 | 規則式後處理（本研究 N = 11，p.1416） |
| 8. 標籤對齊 | PPG 與心電圖時間同步 | 時間戳對齊、加緩衝（本研究 ±1 分鐘，p.1417） |
| 9. 評估 | 以「人」為單位切分訓練／測試 | PPV、敏感度、特異度、Clopper-Pearson CI；注意盛行率對 PPV 的影響 |
| 10. 統計軟體 | — | 本研究用 Python 3.7 與 R 4.1.0（p.1418） |

- 難點（⚠️ 推論）：動作雜訊、膚色與配戴鬆緊影響 PPG 品質、心電圖標註成本高、資料隱私。

## 主要結果
### 偵測與確認（p.1415, p.1419）
| 指標 | 結果 |
|---|---|
| 收到 IHRD 通知 | 4,728 人（1.0%）；≥65 歲 3.6%、<65 歲 0.7% |
| 完成遠距看診 | 1,671 人（35.3%） |
| 可分析的心電圖貼片 | 1,057 人 |
| 貼片確認有 AF | 340 人（32.2%） |
| **PPV（主要結果）** | **98.2%**（221/225；95% CI 95.5–99.5%） |
| PPV（≥65 歲） | 97.0%（95% CI 91.4–99.4%） |
| 次要結果：IHRD 中對應到 AF 的 5 分鐘段比例 | 98.1% |

### 探索性分析（p.1419, p.1423）
| 敏感度 | 特異度 | 偽陽性率 |
|---|---|---|
| 67.6%（95% CI 62.4–72.6%） | 98.4%（95% CI 97.3–99.2%） | 1.5% |

- 75.9% 的 IHRD 發生在睡眠中；手錶資料在貼片期間每天可分析約 8 小時（p.1419）。
- AF 負荷中位數 7%（有 IHRD 者 14%）；最長發作中位數 7 小時（p.1419–1420）。
- 收到通知者的特徵：較老、男性較多、AF 家族史、心血管病史、睡眠呼吸中止較多（p.1419）。
- 收到通知者回報新診斷 AF 27–34%，未收到者約 1%（p.1421–1422）。
- 無嚴重不良事件；皮膚刺激 0.21%、焦慮 0.25%（p.1421）。

## 作者自述的限制（p.1423）
1. **PPV 可能高估**：PPV 是在「已經收到過 IHRD」的人身上算的，這群人 AF 比例較高；一般族群的第一次 IHRD，PPV 可能較低。
2. 敏感度不完美（約 68%）：只在靜止時運作、需 ≥30 分鐘，可能漏掉活動中的 AF。
3. 大量流失：多數收到通知者沒有參加遠距看診（很多人改找自己的醫師）；問卷回覆率低，遺漏可能不是隨機的。
4. 參與者是既有 Fitbit 使用者，可能本來就擔心心律；買不起裝置的人沒被納入。
5. 心電圖只由一位醫師判讀，可能誤判。
6. 演算法在伺服器運算，無法即時通知。
7. 無法取得病歷，無法評估通知對醫療結果與利用的影響；篩檢的成本效益仍不確定。

## 評析
- 優點：樣本極大、事先註冊與固定演算法、事先計算樣本數、同步比對參考標準、分層報告、涵蓋多款裝置與 iOS／Android、女性與年長者比例比前人研究高（p.1423）。
- ⚠️ 推論：**廠商主導**：Fitbit 出資，研究設計由 Fitbit 參與規劃，3 位作者是 Fitbit 員工；統計分析由麻州總醫院執行（p.1418, p.1424）。
- ⚠️ 推論：**PPV 的富集偏誤**：和 [[lin2022point]] 的教訓相同——PPV 會隨族群盛行率改變（見 [[sensitivity-specificity-ppv-npv]]）。
- ⚠️ 推論：演算法細節與資料不公開，無法重現（p.1416, p.1418）。
- ⚠️ 推論：原文表格編號與內文不一致（內文稱敏感度在 Table 2，實際在 Table 3）；新診斷 AF 人數內文 2363、表格 2357（p.1419, p.1421–1422）。
- 與前人比較：Apple Heart Study PPV 84%、Huawei Heart Study 87%；作者認為較嚴格的連續判定可能降低偽陽性，但研究族群不同，無法正式比較（p.1422）。

## 與其他文獻的關係
- 與 [[kausch2024apnea]]：都用**連續生理訊號**（Kausch：NICU 監視器；Lubitz：穿戴裝置 PPG）。差別：Kausch 是「提前預測」（未來 3 天），Lubitz 是「同時偵測」（當下是否 AF）。
- 與 [[lin2022point]]：都討論 **PPV 與盛行率**；Lin 的高鉀 PPV 很低（盛行率低），Lubitz 的 PPV 很高（在已富集的族群中計算）。
- 與 [[ada2026prevention]]：兩篇都碰到「篩檢」議題——找出未診斷的人，但篩檢的成本效益仍需研究（p.1423）。

## 對我的研究有什麼用
- **穿戴裝置資料的研究範本** ⭐：滑動視窗 + 連續 N 段規則 + 只用靜止時段 + 同步參考標準。
- **研究設計範本** ⭐：事先註冊、固定演算法、樣本數計算、分層報告。
- **自己跑模型的技術清單** ⭐：見上方表格與 [[ppg-af-modeling-pipeline]]。
- **討論段觀點**：PPV 在富集族群會被高估；遠距研究的流失問題。
